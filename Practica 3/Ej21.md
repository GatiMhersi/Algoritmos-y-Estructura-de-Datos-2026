## Enunciado
Muestra los pasos de reducción hasta llegar a la forma normal de la expresión:
`2 * cuadrado (hd [2,4,5,6,7,8])`

Considerando las siguientes definiciones para `cuadrado` y `head` (`hd`):
```haskell
cuadrado :: Int -> Int
cuadrado x = x * x

hd :: [a] -> a
hd (x:xs) = x

```

---

## a) Orden de Reducción Aplicativo

> **Regla:** Se reduce siempre la expresión más adentro y más a la izquierda (se evalúan los argumentos primero).

1. $2 * \text{cuadrado } (\text{hd } (2 : [4,5,6,7,8]))$
2. $2 * \text{cuadrado } 2$ *(Se evalúa el argumento interno `hd`)*
3. $2 * (2 * 2)$ *(Se aplica la definición de `cuadrado`)*
4. $2 * 4$ *(Se resuelve la multiplicación interna)*
5. **$8$** *(Forma normal alcanzada)*

---

## b) Orden de Reducción Normal

> **Regla:** Se reduce siempre la expresión más afuera y más a la izquierda (se expande la función principal antes de evaluar sus argumentos).

1. $2 * \text{cuadrado } (\text{hd } [2,4,5,6,7,8])$
2. $2 * ((\text{hd } [2,4,5,6,7,8]) * (\text{hd } [2,4,5,6,7,8]))$ *(Se aplica `cuadrado` exteriormente)*
3. $2 * (2 * (\text{hd } [2,4,5,6,7,8]))$ *(Se evalúa la primera aparición de `hd`)*
4. $2 * (2 * 2)$ *(Se evalúa la segunda aparición de `hd`)*
5. $2 * 4$ *(Se resuelve la multiplicación interna)*
6. **$8$** *(Forma normal alcanzada)*
